##  Getting Started in 3 Steps

### 1. Set Up Your Environment
Follow the setup instructions for the specific component you want to work on:
* **Frontend (Nuxt / Vue):** See `documentation/frontend/index.md`
* **Catalog / Ingestion Pipeline:** See `documentation/catalog/index.md`
* **API / Backend (Django):** See `documentation/api/index.md`

### 2. Find an Issue
Look for issues labeled **`good first issue`** or **`help wanted`** on GitHub. Leave a comment on the issue asking to be assigned before starting work.

### 3. Contribution Practices
* Create a feature branch off of `main` (e.g., `git checkout -b fix/issue-description`).
* Keep commits focused and write descriptive commit messages.
* Open a Pull Request targeting the `main` branch and link the issue in the description using `Fixes #<issue-number>`.
